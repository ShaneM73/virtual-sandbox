About

Designed by Xin Miao, Missouri State University. The idea is to move the physical AR Sandbox into a virtual 3D world that any student can open in a web browser on Windows, with no Linux computer, depth camera or projector needed.

Based on the Augmented Reality Sandbox by Oliver Kreylos (UC Davis KeckCAVES, 2012), built for the NSF-funded LakeViz3D project and now used at more than 150 sites worldwide. The water is the original SARndbox 2.8 solver, a Kurganov–Petrova shallow-water scheme, ported from GLSL to WebGL2 with the same constants (θ = 1.3, g = 9.81, attenuation 127/128). The virtual box is 160 × 120 cm on a grid.

Added beyond the original: angle-of-repose sand slumping, springs, sinkholes, Green–Ampt infiltration and a flow-speed view. The original is GPL-2.0-or-later, and this port carries the same license. Original project page · Source code and VR version
